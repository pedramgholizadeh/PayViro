Webiro Gateway

API Reference

همه‌ی مسیرها زیر آدرس پایه https://webiro.ir/gateway سرو می‌شوند. فرمت درخواست و پاسخ JSON است و پارامترهای متنی UTF-8 می‌پذیرند.

احراز هویت: هر درخواستِ مسیرهای /api/v1 باید هدر X-API-Key داشته باشد؛ معادل آن هدر استاندارد Authorization: Bearer <key> هم پذیرفته می‌شود.

ایجاد پرداخت#

POST/api/v1/paymentsساخت تراکنش و دریافت لینک پرداخت
Request
curl -X POST https://webiro.ir/gateway/api/v1/payments \
  -H "X-API-Key: wgr_..." \
  -H "Content-Type: application/json" \
  -d '{
        "amount": 2500000,
        "currency": "toman",
        "gateway": "auto",
        "callback_url": "https://lahze-app.ir/payment/result",
        "order_id": "ORD-101",
        "description": "خرید اشتراک یک‌ساله",
        "mobile": "09121234567",
        "webhook_url": "https://lahze-app.ir/api/payment/webhook",
        "idempotency_key": "ORD-101"
      }'
پارامترالزامینوعتوضیح
amountبلهintegerمبلغ بر حسب واحد currency — عدد صحیح مثبت.
currencyخیرstringrial (پیش‌فرض) یا toman — ذخیره‌سازی و همه‌ی پاسخ‌ها به ریال است.
callback_urlبلهstringآدرس بازگشت کاربر پس از پرداخت؛ باید HTTPS و هم‌دامنه با callback_domain پذیرنده باشد.
gatewayخیرstringsaman · pasargad (اولویت) · zarinpal · zibal · idpay · nextpay · payping · sepordeh · payir · aqayepardakht · vandar · bluebank · snappay · digipay · tara · lendo · ghasta (قسطی) · oxapay (کریپتو) · test · auto (پیش‌فرض کانفیگ).
order_idخیرstringشناسه‌ی سفارش شما (حداکثر ۶۴ کاراکتر) — در callback و وبهوک عودت داده می‌شود.
descriptionخیرstringشرح تراکنش (حداکثر ۵۰۰ کاراکتر).
mobileخیرstringموبایل خریدار 09xxxxxxxxx — به بانک هم ارسال می‌شود.
webhook_urlخیرstringدر صورت ارسال، بر مقدار پیش‌فرض پذیرنده اولویت دارد.
idempotency_keyخیرstringبا تکرار همین کلید، همان تراکنش قبلی برگردانده می‌شود (بدون تراکنش تکراری).
metadataخیرobjectداده‌ی دلخواه شما؛ در پنل مدیریت و پاسخ‌های داخلی دیده می‌شود.

کرون وبهوک#

GET/api/cron/webhooks?key=…ارسال وبهوک‌های معوق + انقضای تراکنش‌ها
Response
{
  "status": "success",
  "data": {
    "time": "2026-10-27 21:25:00",
    "expired_transactions": 0,
    "webhooks": { "processed": 1, "sent": 1, "failed": 0 }
  }
}

این مسیر با کلید کرون (cron.key در کانفیگ) احراز می‌شود، نه کلید پذیرنده. برای تنظیم کرون سی‌پنل بخش نصب را ببینید.

کدهای خطا#

خطاها همیشه با این ساختار برمی‌گردند:

401 Unauthorized
{
  "status": "error",
  "error": {
    "code": "unauthorized",
    "message": "کلید API نامعتبر است."
  }
}
کد HTTPکد خطامعنی
400invalid_requestپارامتر نامعتبر — فیلد مشکل‌دار در error.field.
400gateway_unavailableدرگاه انتخابی فعال/پیکربندی نشده.
401unauthorizedکلید API ارسال نشده یا نامعتبر است.
403merchant_disabledحساب پذیرنده غیرفعال شده.
403forbidden_callbackدامنه‌ی callback_url با دامنه‌ی مجاز پذیرنده نمی‌خواند.
403gateway_forbiddenاین درگاه برای این پذیرنده مجاز نیست.
404not_foundمسیر یا تراکنش یافت نشد.
429rate_limitedبیش از حد مجاز (پیش‌فرض ۶۰ درخواست در دقیقه).
500internal_errorخطای داخلی — جزئیات در لاگ سرور.
502gateway_rejected / driver_errorدرگاه بانکی درخواست را رد کرد یا ارتباط برقرار نشد.
503config_missing / cron_disabledکانفیگ ناقص است.

نکته: پیام‌های خطا فارسی و آماده‌ی نمایش به کاربر هستند؛ error.code را برای منطق برنامه‌ی خودتان استفاده کنید.
