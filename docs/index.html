Webiro Gateway

درگاه پرداخت وبیرو (PayViro)

یک نقطه‌ی اتصال روی webiro.ir/gateway که درگاه‌های پرداخت وبیرو را برای همه‌ی دامنه‌های شما فراهم می‌کند — بدون نیاز به درگاه و ای‌نماد جداگانه روی هیچ دامنه‌ی دیگری.

یک کلید برای هر دامنه

هر دامنه (lahze-app.ir، webirox.ir و…) یک API Key مستقل می‌گیرد؛ دامنه‌ی مجاز، آدرس بازگشت و وبهوک مخصوص خودش را دارد.

۱۸+ درگاه، یک API

بانک سامان و پاسارگاد در اولویت + زرین‌پال، زیبال، آیدی‌پی، نکست‌پی، پی‌پینگ، سپرده، Pay.ir، آقای پرداخت، وندار، بلوبانک، درگاه‌های قسطی (اسنپ‌پی، دیجی‌پی، تارا، لندو، قسطا) و کریپتو (OxaPay).

امنیت با امضای HMAC

هم ریدایرکت بازگشت و هم وبهوک با امضای HMAC-SHA256 محافظت می‌شوند؛ دستکاری مبلغ یا وضعیت قابل تشخیص است.

پنل مدیریت و وبهوک

داشبورد آماری، جزئیات تراکنش‌ها، ارسال مجدد وبهوک و خروجی CSV در /gateway/admin.

معماری#

دامنه‌های شما هرگز مستقیماً با بانک صحبت نمی‌کنند؛ همه‌چیز از گیت‌وی وبیرو عبور می‌کند. به این ترتیب اعتبار درگاه‌ها و ای‌نماد فقط روی وبیرو لازم است.

شروع سریع در ۵ دقیقه#

کلید API برای دامنه بسازید

روی سرور وبیرو، برای هر دامنه یک کلید بسازید و تکه‌ی خروجی را در config/config.php بخش merchants اضافه کنید:

SSH / Terminal
php /home/username/public_html/gateway/tools/make-api-key.php "lahze-app" "https://lahze-app.ir"

از دامنه‌ی خودتان درخواست پرداخت بزنید

start-payment.php
require 'PayViro.php';

$gateway = new PayViro(
    'https://webiro.ir/gateway',
    'wgr_...',   // API Key این دامنه
    'wgs_...'    // Secret برای بررسی امضا
);

$payment = $gateway->requestPayment([
    'amount'       => 2500000,                                // ریال
    'callback_url' => 'https://lahze-app.ir/payment/result',
    'order_id'     => 'ORD-101',
    'description'  => 'خرید اشتراک یک‌ساله',
    'gateway'      => 'auto',
]);

header('Location: ' . $payment['payment_url']);
exit;
cURL
curl -X POST https://webiro.ir/gateway/api/v1/payments \
  -H "X-API-Key: wgr_..." \
  -H "Content-Type: application/json" \
  -d '{
        "amount": 2500000,
        "callback_url": "https://lahze-app.ir/payment/result",
        "order_id": "ORD-101",
        "gateway": "auto"
      }'

در صفحه‌ی بازگشت، امضا را تایید کنید

پس از پرداخت، کاربر با پارامترهای امضاشده به callback_url شما برمی‌گردد. فقط کافی است امضا را بررسی کنید (و توصیه‌شده: استعلام وضعیت هم بگیرید):

payment/result.php
$result = $gateway->verifyRedirect();  // امضای sig بررسی می‌شود

if ($result['ok']) {
    // سفارش را پرداخت‌شده کنید:  UPDATE orders SET paid=1 WHERE order_id=?
}

بدون پول تست کنید: درگاه test داخلی، یک صفحه‌ی شبیه‌ساز بانک دارد و کل جریان (callback، verify، وبهوک، امضا) را دقیقاً مثل بانک واقعی اجرا می‌کند. کافی است "gateway": "test" بفرستید.
